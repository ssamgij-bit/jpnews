# 일본 증시 뉴스 봇 (jpnews)

니케이·로이터 일본어판·블룸버그 일본어판·NHK(경제·정치·국제·사회)의 새 기사를 10분마다 확인합니다. 기사마다 한국어로 번역하고 중요도 점수(1~5)를 매긴 뒤 텔레그램 채널로 보냅니다.

- **★4 이상**: 바로 알림. 한국어 제목, 원제, 사실, 영향 종목·섹터, 해석(추정), 원문 링크
- **★3**: 평일 15:45(일본 시간) 장 마감 후 다이제스트 하나로 묶어서 발송
- **★1~2와 중복 기사**: 보내지 않음. 같은 사건을 여러 매체가 보도하면 1건만 보냄(최근 36시간 기준)

## 설치 (약 10분)

1. **텔레그램**
   - 채널을 새로 만들고, 봇을 채널 관리자로 추가합니다. 새 봇은 @BotFather에서 만들 수 있고, 기존 봇을 써도 됩니다.
   - 채널 ID(`-100…`)를 확인합니다. 채널에 아무 글이나 올린 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`에서 `chat.id`를 보면 됩니다.
2. **Gemini API 키**: https://aistudio.google.com/apikey 에서 발급합니다. 이미 쓰는 키가 있으면 그대로 써도 됩니다.
3. **GitHub 저장소**
   - 새 저장소(예: `jpnews`)를 **Public**으로 만들고 이 폴더의 파일을 전부 올립니다.
   - Private 저장소는 무료 Actions 사용량(월 2,000분)을 넘깁니다. 10분마다 실행하면 월 약 4,300회가 실행되기 때문입니다.
4. **Settings → Secrets and variables → Actions**에 다음 Secret 3개를 등록합니다.
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `GEMINI_API_KEY`
5. **Actions 탭 → jp-news-bot → Run workflow**로 한 번 실행합니다.
   - 첫 실행은 현재 기사를 기준선으로 저장만 하고 메시지는 보내지 않습니다.
   - 두 번째 실행부터 알림이 옵니다.

## 조정 (Settings → Variables, 선택 사항)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `SCORE_THRESHOLD` | 4 | 즉시 알림을 보내는 최소 점수 |

알림이 너무 많거나 적으면 bot.py의 `PROMPT` 안에 있는 중요도 기준 문장을 고치는 것이 가장 효과적입니다.

## 참고

- 니케이 유료 기사는 제목과 무료 리드 문장까지만 읽습니다. 로이터·블룸버그는 제목만 읽기 때문에 '해석' 항목은 추정 수준입니다.
- 소스 URL은 2026-10-05에 확인했습니다. NHK는 2026-08에 RSS 주소가 `news.web.nhk`로 바뀌었고, 예전 주소는 더 이상 갱신되지 않습니다.
- Gemini 무료 사용 한도는 계정마다 다릅니다(AI Studio에서 확인). 한도를 넘기면 기사를 보관해 두고 다음 실행 때 다시 시도합니다. 3시간 넘게 계속 실패하면 원제 그대로 다이제스트에 넣습니다.
- 수동 테스트: `DRY_RUN=1 python bot.py`를 실행하면 텔레그램으로 보내지 않고 화면에만 출력합니다.

# 일본 커뮤니티 화제글 (community.py)

하테나 북마크 인기 엔트리(종합), 걸즈채널 오늘의 인기 토픽, 토게터 주목 정리에서 화제인 글을 골라 같은 채널로 보냅니다. 글마다 한국어 제목, 내용 요약, 댓글 반응 요약, 원문·댓글 링크를 붙입니다.

- **수집**: 매시 50분에 각 사이트의 북마크·댓글·조회 수를 기록합니다.
- **다이제스트**: 매일 00:00, 06:00, 12:00, 18:00(KST) 4회 보냅니다. 00시와 06시는 알림 소리 없이 보냅니다.
  - 지난 약 6시간 동안 북마크·댓글·조회 수가 가장 많이 늘어난 글을 사이트당 2건씩, 최대 6건 보냅니다.
  - 기준을 넘는 새 글이 없으면 그 회차는 보내지 않습니다. 한 번 보낸 글은 다시 보내지 않습니다(14일 기준).
- **즉시 알림**: 상장사·증시 관련성이 ★4 이상인 글은 다이제스트를 기다리지 않고 바로 보냅니다. 대형 불매, 리콜·식품 사고, 정보 유출 같은 글이 해당합니다.
- **제외**: 걸즈채널의 상시 잡담·실황 시리즈 토픽(Part○, 실황·감상 등)은 화제글로 보지 않습니다.
- 첫 실행은 기준선만 저장하고 보내지 않습니다.
- 테스트는 Actions → jp-community-bot → Run workflow에서 `digest_now`를 체크하고 실행하면 바로 다이제스트가 옵니다.

## 조정 (Settings → Variables, 선택 사항)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `HATENA_MIN` | 100 | 하테나 최소 북마크 수 |
| `GIRLS_MIN` | 300 | 걸즈채널 최소 댓글 수 |
| `TOGETTER_MIN` | 20000 | 토게터 최소 조회 수 |
| `PER_SOURCE` | 2 | 다이제스트당 사이트별 최대 건수 |
| `COMMUNITY_THRESHOLD` | 4 | 즉시 알림을 보내는 최소 점수 |

시크릿은 뉴스봇과 같은 것(`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `GEMINI_API_KEY`, `TELEGRAM_ADMIN_CHAT_ID`)을 그대로 씁니다. 따로 등록할 것은 없습니다.

## 주간 기업·브랜드 언급 순위

매주 일요일 18:00 다이제스트 뒤에 지난 7일 화제글에서 많이 언급된 기업·브랜드 10개를 언급 건수, 여론 분위기(긍정·부정·혼재), 화제 요지와 함께 보냅니다. 이어서 커뮤니티 화제글·브랜드 순위·한 주간 X 트렌드를 종합한 투자 아이디어·인사이트 3~5개(관찰 사실, 시사점(추정), 관련 종목·업종, 반대 논거·리스크)를 별도 메시지로 보냅니다. 테스트는 Run workflow에서 `weekly_now`를 체크합니다.

## 뉴스 연계

다이제스트 글이 뉴스봇이 최근 24시간 안에 보낸 기사와 같은 사건이면 `[뉴스 연계]`로 그 기사 제목을 붙입니다.

## X 트렌드 (trends24)

다이제스트 회차(00·06·12·18시)마다 별도 메시지로 일본 X 트렌드 최근 6시간 상위 10개를 보냅니다. trends24의 시간대별 순위(각 50위)를 최근 6시간 합산해 고르고, 키워드마다 분류, 화제 이유(최근 1일 일본 뉴스 제목 근거, 근거가 없으면 '(추정)' 표시), X 검색 링크를 붙입니다. 상장사와 직접 관련되면 티커도 붙입니다. 테스트는 Run workflow에서 `x_now`를 체크합니다.
