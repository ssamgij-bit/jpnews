# 일본 증시 뉴스 봇 (jpnews)

니케이·로이터 일본어판·블룸버그 일본어판·NHK(경제·정치·국제·사회)의 새 기사를 10분마다 확인합니다. 기사마다 한국어로 번역하고 중요도 점수(1~5)를 매긴 뒤 텔레그램 채널로 보냅니다.

- **★4 이상**: 바로 알림. 한국어 제목, 원제, 사실, 영향 종목·섹터, 해석(추정), 원문 링크
- **★3**: 평일 15:45(일본 시간) 장 마감 후 다이제스트 하나로 묶어서 발송
- **★1~2와 중복 기사**: 보내지 않음. 같은 사건을 여러 매체가 보도하면 1건만 보냄(최근 36시간 기준)

## 설치 (약 10분)

1. **텔레그램**
   - 채널을 새로 만들고, 봇을 채널 관리자로 추가합니다. 새 봇은 @BotFather에서 만들 수 있고, 기존 봇을 써도 됩니다.
   - 채널 ID(`-100…`)를 확인합니다. 채널에 아무 글이나 올린 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`에서 `chat.id`를 보면 됩니다.
2. **Gemini API 키**: https://aistudio.google.com/apikey 에서 발급합니다. 이미 쓰는 키가 있으면 그대로 써도 됩니다.
3. **GitHub 저장소**
   - 새 저장소(예: `jpnews`)를 **Public**으로 만들고 이 폴더의 파일을 전부 올립니다.
   - Private 저장소는 무료 Actions 사용량(월 2,000분)을 넘깁니다. 10분마다 실행하면 월 약 4,300회가 실행되기 때문입니다.
4. **Settings → Secrets and variables → Actions**에 다음 Secret 3개를 등록합니다.
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `GEMINI_API_KEY`
5. **Actions 탭 → jp-news-bot → Run workflow**로 한 번 실행합니다.
   - 첫 실행은 현재 기사를 기준선으로 저장만 하고 메시지는 보내지 않습니다.
   - 두 번째 실행부터 알림이 옵니다.

## 조정 (Settings → Variables, 선택 사항)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `SCORE_THRESHOLD` | 4 | 즉시 알림을 보내는 최소 점수 |

알림이 너무 많거나 적으면 bot.py의 `PROMPT` 안에 있는 중요도 기준 문장을 고치는 것이 가장 효과적입니다.

## 참고

- 니케이 유료 기사는 제목과 무료 리드 문장까지만 읽습니다. 로이터·블룸버그는 제목만 읽기 때문에 '해석' 항목은 추정 수준입니다.
- 소스 URL은 2026-10-05에 확인했습니다. NHK는 2026-08에 RSS 주소가 `news.web.nhk`로 바뀌었고, 예전 주소는 더 이상 갱신되지 않습니다.
- Gemini 무료 사용 한도는 계정마다 다릅니다(AI Studio에서 확인). 한도를 넘기면 기사를 보관해 두고 다음 실행 때 다시 시도합니다. 3시간 넘게 계속 실패하면 원제 그대로 다이제스트에 넣습니다.
- 수동 테스트: `DRY_RUN=1 python bot.py`를 실행하면 텔레그램으로 보내지 않고 화면에만 출력합니다.
